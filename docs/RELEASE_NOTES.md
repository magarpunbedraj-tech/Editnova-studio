## EditNova Studio 1.0

The first public release: a free, offline video editor for Windows.

**Install:** download `EditNova-Studio-Setup.exe` below and run it. If Windows
SmartScreen warns you, choose **More info → Run anyway**. Everything you need,
including the FFmpeg video engine, is in the installer.

### What you can do
- Import videos with the button or by dropping them on the window
- Trim, split, reorder by dragging, duplicate and delete clips, with undo/redo
- Fade in and out from black, mute or change each clip's volume (up to 200 %)
- Export MP4 for landscape, 4K, vertical (Reels, Shorts, TikTok), square and 4:5
- Fast exports on NVIDIA graphics cards, with progress and time remaining
- Save projects, reopen recent ones, recover after a crash

### Files
- `EditNova-Studio-Setup.exe` — always the latest installer
- `EditNova-Studio-<version>-Setup.exe` — the same installer with its version in the name
- `SHA256SUMS.txt` — checksums to verify your download
- `ffmpeg-source-*.tar.gz` — source of the bundled FFmpeg (GPL)
